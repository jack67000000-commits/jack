# Winking 游戏预测平台

这个仓库已经把公开前台和中文管理后台界面放在同一个项目中：

- `/`：公开的阿根廷西班牙语游戏预测页面。
- `/admin/*`：中文管理后台界面原型。
- `app/game-catalog.json`：当前前台游戏目录数据。

## 当前安全边界

管理后台目前只有界面原型，尚未连接真实登录、数据库和图片存储。为避免演示登录被误当成安全后台，生产构建会自动隐藏全部 `/admin/*` 路由。

本地查看后台原型时，在开发环境设置 `WINKING_ADMIN_PREVIEW=true`。正式上线后台前，需要完成：

1. 服务端登录验证，并只允许授权邮箱 `jack67000000@gmail.com`。
2. 数据库存储游戏名称、图片、预测参数、排序、状态和跳转链接。
3. 图片云存储、操作日志、备份与恢复。
4. 服务端权限检查；不能依赖浏览器的 `sessionStorage`。

## 发布与修改

- 界面、程序、数据结构有变化：提交到 GitHub，然后重新部署。
- 后台正式接入数据库后，日常修改游戏名称、图片、参数和链接：直接在后台保存，不需要再次提交 GitHub，也不需要重新部署。
- GitHub 是代码与版本记录；部署平台才是真正运行网站的地方。

## 本地开发

```bash
npm install
npm run dev
npm run build
```

项目要求 Node.js `>=22.13.0`。
